# Âm thanh Voice Coach

`vi-mai-anh.mp3` dùng giọng Mai Anh – Vietnamese News Anchor từ ElevenLabs.

`vi_cues.mjs` ghi vị trí và độ dài từng đoạn theo giây. Các mục 0–100 đọc số tương ứng. Mục 101 xác nhận bật giọng, mục 102 nhắc hạ thấp khi squat, mục 103 nhắc lùi khỏi camera, mục 104 nhắc xoay sang góc nhìn ngang và mục 105 nhắc điều chỉnh khung hình. Cập nhật các mốc phát khi thay file MP3.

Với số lần lặp trên 100, Voice Coach đọc từng chữ số bằng các đoạn 0–9 trong file MP3.
