# FitSense

Trợ lý tập luyện cá nhân. Bảng phân công và báo cáo kiến trúc nằm trong thư mục `docs/`.

## Chạy giao diện khởi đầu

Từ thư mục dự án, sau khi kích hoạt môi trường Python:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

SCRUM-14 phụ trách MediaPipe Pose, đo góc gối và khuỷu tay từ camera.
